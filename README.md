# Проект: Игра "Раскраска по цветам" (Color By Number) для мобильных устройств

## Обзор
Этот проект представляет собой полностью готовый каркас для мобильной игры-раскраски на движке Unity. Игрок выбирает цвет из палитры и закрашивает соответствующие зоны на изображении. **Включена поддержка загрузки пользовательских фото** с автоматической обработкой в контурный рисунок.

## 📁 Структура проекта

```
Assets/
├── Scripts/
│   ├── GameManager.cs        # Главный менеджер игры (синглтон)
│   ├── ColorZone.cs          # Логика зоны раскраски
│   ├── ColorPicker.cs        # Выбор цвета + ColorInputManager
│   ├── ZoneClickHandler.cs   # Обработка кликов по зонам
│   └── ImageProcessor.cs     # Загрузка и обработка фото
├── Scenes/
│   ├── GameScene.unity       # Основная сцена игры
│   └── MainMenu.unity.meta   # Мета-файл для сцены меню
├── Prefabs/
│   ├── UI/
│   │   └── ColorButton.prefab # Префаб кнопки цвета
│   └── Zones/
│       └── ColorZone.prefab   # Префаб зоны раскраски
└── Sprites/                   # Папка для ваших спрайтов
```

## 🎮 Как это работает

1. **Старт:** Игрок видит серые контуры (зоны) и палитру цветов внизу экрана.
2. **Выбор:** Игрок нажимает на цвет в палитре (`ColorPicker`). Цвет сохраняется в `ColorInputManager`.
3. **Действие:** Игрок нажимает на зону на картинке (`ZoneClickHandler`).
4. **Проверка:** 
   - Скрипт зоны сравнивает выбранный цвет с правильным (`targetColor`).
   - Если цвета совпадают → Зона закрашивается, счетчик увеличивается.
   - Если нет → Зона мигает красным (ошибка).
5. **Победа:** Когда все зоны закрашены, `GameManager` показывает сообщение о победе.

### 📸 Загрузка пользовательских фото

Скрипт `ImageProcessor.cs` позволяет игрокам загружать свои фотографии:

1. **Загрузка:** Из галереи или камеры устройства.
2. **Обработка:**
   - **Ресайз:** Оптимизация размера для производительности.
   - **Постеризация:** Упрощение цветовой гаммы (эффект мультфильма).
   - **Выделение границ:** Преобразование в черно-белый контур (оператор Собеля).
3. **Результат:** Готовый контурный рисунок отображается на экране.

## 🚀 Быстрый старт

### 1. Создание проекта в Unity
- Откройте **Unity Hub**.
- Создайте новый **2D Core** проект.
- Дождитесь окончания импорта ассетов.

### 2. Импорт файлов проекта
- Скопируйте **все содержимое** этого репозитория в корень вашего проекта Unity.
- Или просто клонируйте репозиторий и откройте папку как проект Unity.

### 3. Настройка сцены

#### A. GameManager
1. В сцене `GameScene.unity` уже создан объект **GameManager**.
2. Если его нет: создайте пустой GameObject → назовите `GameManager` → добавьте скрипт `GameManager`.
3. В инспекторе задайте:
   - **Available Colors**: список цветов для уровня (размер = количеству уникальных цветов на рисунке).
   - **Total Zones**: общее количество зон (можно оставить 0 для авто-подсчета).

#### B. Зоны раскраски
1. Подготовьте спрайт с изображением-раскраской.
2. Разбейте изображение на отдельные зоны (в Photoshop, Aseprite или через Sprite Atlas).
3. Для каждой зоны:
   - Перетащите спрайт на сцену.
   - Добавьте компоненты: `SpriteRenderer`, `Collider2D` (PolygonCollider2D или BoxCollider2D).
   - Добавьте скрипты: `ColorZone` и `ZoneClickHandler`.
   - В `ColorZone` укажите `Target Color` (правильный цвет) и `Zone ID`.

#### C. Палитра цветов (UI)
1. Создайте **Canvas** (GameObject → UI → Canvas).
2. Внутри Canvas создайте панель для кнопок (GameObject → UI → Panel).
3. Для каждого цвета:
   - Создайте кнопку (GameObject → UI → Button).
   - Добавьте скрипт `ColorPicker`.
   - Укажите `Color Value` (цвет, который представляет кнопка).
   - Настройте внешний вид кнопки (Image.color).

#### D. Загрузка фото (ImageProcessor)
1. На Canvas создайте элемент **RawImage** (GameObject → UI → RawImage).
2. Добавьте на него скрипт `ImageProcessor`.
3. Создайте две кнопки: "Загрузить из галереи" и "Камера".
4. Привяжите кнопки к полям `Load Button` и `Capture Button` в скрипте `ImageProcessor`.
5. *(Опционально)* Создайте панель "Обработка..." (Panel с текстом) и привяжите к `Processing Panel`.

### 4. Установка плагина для галереи (для мобильных устройств)

Для работы загрузки фото на Android/iOS установите плагин **NativeGallery**:

1. Откройте **Window → Package Manager**.
2. Нажмите **+ → Add from Git URL**.
3. Введите URL: `https://github.com/yasirkula/UnityNativeGallery.git`
4. Или скачайте с [Asset Store](https://assetstore.unity.com/packages/tools/integration/native-gallery-for-android-ios-117698).

После установки раскомментируйте код в `ImageProcessor.cs` (секции `#if UNITY_ANDROID || UNITY_IOS`).

### 5. Проверка и запуск
- Нажмите **Play** в редакторе Unity.
- Выберите цвет из палитры.
- Кликните на зону с таким же цветом.
- Зона должна закраситься!

## 🔧 Технические детали

### Скрипты

| Скрипт | Описание |
|--------|----------|
| `GameManager.cs` | Синглтон. Считает прогресс, определяет победу, хранит палитру. |
| `ColorZone.cs` | Хранит целевой цвет, проверяет совпадение, запускает анимацию ошибки. |
| `ColorPicker.cs` | Обрабатывает клик по цвету, сохраняет выбор в `ColorInputManager`. |
| `ColorInputManager` | Статический класс для глобального доступа к текущему цвету. |
| `ZoneClickHandler.cs` | Перехватывает `OnMouseDown`, получает цвет из менеджера, передает в зону. |
| `ImageProcessor.cs` | Загружает фото, применяет фильтры (ресайз, постеризация, Sobel edge detection). |

### Обработка изображений

Алгоритм в `ImageProcessor.cs`:
1. **Загрузка** текстуры из файла.
2. **Resize**: уменьшение до `maxResolutionWidth` (по умолчанию 512px) для скорости.
3. **Posterize**: сокращение количества оттенков до `posterizationLevels` (2-8).
4. **Edge Detection**: оператор Собеля выделяет границы → черно-белый контур.

## 📱 Сборка для мобильных устройств

### Android
1. File → Build Settings → Switch Platform → Android.
2. Player Settings:
   - Company Name, Product Name.
   - Minimum API Level: Android 7.0 (API level 24).
   - Target API Level: Highest installed.
3. Build → APK.

### iOS
1. File → Build Settings → Switch Platform → iOS.
2. Player Settings:
   - Bundle Identifier (например, com.yourstudio.colorbynumber).
   - Target iOS Version: 12.0+.
3. Build → откройте в Xcode → Archive → Upload to App Store.

## 💡 Рекомендации по улучшению

- **Звуки:** Добавьте AudioSource с эффектами клика, успеха и победы.
- **Частицы:** ParticleSystem при закрашивании зоны.
- **Сохранение:** Используйте `PlayerPrefs` или JSON для сохранения прогресса.
- **Уровни:** Создайте систему загрузки разных сцен или ScriptableObject с данными уровней.
- **Авто-генерация зон:** Самая сложная часть — автоматическое создание `ColorZone` из фото. Можно использовать:
  - Алгоритм Connected Components Labeling.
  - Ассеты вроде *2D Auto Sprite Slicer* или *Poly2Tri*.
  - Серверную обработку на Python (OpenCV) с загрузкой готовых зон.
